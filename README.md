# CYBER-X — Cyborg-Themed Landing Page
### Techfest IIT Bombay | Campus Ambassador Task

A cyborg-themed interactive landing page built with vanilla HTML, CSS, and Three.js WebGL. No frameworks, no libraries beyond Three.js — pure browser-native tech.

## Live Demo
🔗 [https://anuragkkumar.github.io/cyborg-landing-page-TECHFEST-IIT-BOMBAY-/](https://anuragkkumar.github.io/cyborg-landing-page-TECHFEST-IIT-BOMBAY-/)

## Features
- **3D WebGL Sphere** — Three.js wireframe icosahedron with a mouse-tracking particle cloud
- **Web Audio API** — Procedural sound synthesizer, no audio files needed
- **Interactive Loadout Panel** — Toggle weapons/armor and watch gauges update in real-time
- **Working CLI Terminal** — Type `scan`, `overclock`, `techfest`, `ca`, `help`, `clear`
- **Overclock Sequence** — Full-screen animated boot routine
- **CRT Scanlines** — Old-school monitor overlay effect
- **Fully Responsive** — Works on mobile and desktop

## Tech Stack
- HTML5 / CSS3
- JavaScript (ES6+)
- Three.js (WebGL)
- Web Audio API

## Run Locally
Just open `index.html` in any browser. No build step needed.
